# ทะเบียนคุม
เว็บไซต์ทะเบียนกิจการที่เป็นอันตรายต่อสุขภาพ สำหรับเทศบาลนครบางบัวทอง

## เริ่มใช้งาน
ต้องมี Python 3.10 ขึ้นไปและอินเทอร์เน็ตสำหรับติดตั้ง openpyxl ครั้งแรก
1. แตก ZIP ทั้งโฟลเดอร์ไว้ในเครื่อง
2. Windows: ดับเบิลคลิก start-windows.bat
3. Mac: เปิด Terminal ในโฟลเดอร์แล้วใช้ bash start-mac.command
4. เบราว์เซอร์เปิด http://127.0.0.1:8000 อัตโนมัติ หากไม่เปิดให้พิมพ์ URL นี้
5. เปิดหน้าต่างโปรแกรมค้างไว้ระหว่างใช้งาน ปิดด้วย Ctrl+C

เริ่มด้วยคำสั่งเอง:
python -m venv .venv
ติดตั้งด้วย python -m pip install -r requirements.txt ภายใน virtual environment
python server.py
เปลี่ยนพอร์ต: python server.py --port 8001
ไม่เปิดเบราว์เซอร์: python server.py --no-browser

## ความสามารถ
- ข้อมูลเริ่มต้น 388 รายการ จาก 18 แผ่นงานที่มีหัวตารางของไฟล์ที่ส่งมา
- ค้นหาชื่อ ที่อยู่ ประเภทกิจการ รหัส หรือเลขใบอนุญาต
- กรองหมวด เลือกปีงบประมาณ แบ่งหน้า
- เพิ่ม แก้ไข ลบทะเบียน พร้อมประวัติใบอนุญาตรายปี
- นำเข้า .xlsx แบบเพิ่มรายการ (การนำเข้าซ้ำทำให้รายการซ้ำ)
- ส่งออก CSV ของรายการที่กรองและปีที่เลือก เปิดด้วย Excel ได้
- สำรอง JSON ทั้งฐานข้อมูล และกู้คืนแบบแทนที่ทั้งหมด
- บันทึก SQLite ถาวรบนเครื่อง ข้อมูลยังอยู่เมื่อปิดโปรแกรม

## โครงสร้าง
server.py : เว็บเซิร์ฟเวอร์และ API ด้วย Python standard library
importer.py : แปลง Excel โครงสร้างทะเบียนคุม
static/ : HTML, CSS, JavaScript ไม่ต้อง build และไม่ใช้ CDN
requirements.txt : dependency
start-windows.bat / start-mac.command : สคริปต์เริ่มใช้งาน
data/initial.json : ข้อมูลเริ่มต้นที่แปลงจาก Excel
data/registry.sqlite3 : สร้างเมื่อเปิดครั้งแรก เป็นข้อมูลที่แก้ไขแล้ว

## ข้อมูลต้นฉบับและข้อจำกัด
- ไม่นำเข้าแถวแบบฟอร์มว่างหรือ Sheet1 ที่ไม่มีข้อมูล
- หมวด1 มีหัวแผ่นงานระบุหมวด13 แต่ไม่มีรายการ ระบบเก็บชื่อแท็บเป็นหมวด และเก็บ source_title ใน initial.json ไว้ตรวจสอบ
- รักษาข้อความชื่อ ที่อยู่ รหัส และวันที่ต้นฉบับ รวมถึงค่าปีที่อาจผิด เช่น 0569 และ 1965 ไม่แปลงหรือแก้ไขเอง
- วันเวลาจาก Excel ถูกเก็บเป็นข้อความ วัน/เดือน/ปีตามปีที่ระบุในไฟล์ ไม่บวก 543 ซ้ำ
- จำนวนใบอนุญาตบนหน้าจอหมายถึงมีเลขใบอนุญาตในปีที่เลือก ไม่ได้ยืนยันว่าใบอนุญาตยังมีผล
- ค่าธรรมเนียมเป็นข้อมูลระดับกิจการตามไฟล์ ไม่ใช่ประวัติยอดชำระรายปี
- เปิดให้ใช้เฉพาะเครื่องเดียวผ่าน 127.0.0.1 ไม่มีบัญชีผู้ใช้หรือสิทธิ์เข้าถึงสำหรับการใช้ร่วมกัน ไม่พร้อมเผยแพร่สู่สาธารณะ
- ข้อมูลมีชื่อ ที่อยู่ เบอร์โทร และข้อมูลส่วนบุคคลตามต้นฉบับ เก็บ ZIP และไฟล์สำรองไว้ในพื้นที่งานที่เหมาะสม
- สำรองผ่านปุ่ม JSON หรือปิดโปรแกรมก่อนคัดลอก registry.sqlite3
- หากต้องการใช้หลายเครื่องพร้อมกัน ต้องเพิ่มระบบเข้าสู่ระบบ สิทธิ์ และเซิร์ฟเวอร์ก่อนนำไปใช้งานจริง

## API
GET /api/records
POST /api/records
PUT /api/records/{id}
DELETE /api/records/{id}
POST /api/import (ไฟล์ Excel bytes สูงสุด 15 MB)
POST /api/restore (JSON records/categories)
